\# MW PRB Email Automation



Automates extraction of PRB ticket IDs from Outlook emails

and logs them into an Excel tracker.



\## Features

\- Offline `.msg` parsing

\- Outlook folder-based processing

\- Sender + subject filtering

\- Duplicate-safe Excel updates



\## Requirements

\- Windows

\- Outlook Desktop

\- Python 3.x

\- pywin32, openpyxl



\## Notes

Excel data files and emails are intentionally excluded.
